# Editor-Collab

## Disclaimer

   > This project is in no way affiliated intellectually or realistically with Alkime's (Alk1m3's) Editor Collab.
    This is a personal project that I am working on to learn more about collaborative editing and real-time communication, and in no way should it feel like a copy of Alkime's Editor Collab. I am not affiliated with Alkime in any way, and this project is purely for my own research.

## Features:

- Real-time collaborative editing
- User authentication and authorization
- Document versioning and history
